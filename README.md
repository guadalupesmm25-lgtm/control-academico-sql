# Control Académico y Gestión de Alumnos (SQL Server)

## 📝 Descripción
Este proyecto consiste en el diseño, estructuración y saneamiento de una base de datos relacional para el control académico de una institución educativa. Está desarrollado mediante scripts en SQL Server (T-SQL), implementando conceptos clave de modelado de datos como integridad referencial, restricciones de dominio e inclusión de valores predeterminados.

## 🎯 Objetivo Principal
Construir la arquitectura de base de datos para registrar alumnos, cursos e inscripciones, asegurando la consistencia e integridad de la información mediante la aplicación progresiva de claves primarias, claves foráneas y reglas de negocio automatizadas (como la validación de mayoría de edad).

## 🛠️ Competencias Adquiridas
- **Diseño e implementación:** Diseñar e implementar bases de datos relacionales en SQL Server mediante lenguaje DDL (`CREATE`, `ALTER`, `ADD CONSTRAINT`).
- **Garantía de calidad e integridad:** Garantizar la calidad e integridad de los datos mediante el uso de restricciones `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL` y `CHECK`.
- **Saneamiento de datos:** Saneamiento y corrección de inconsistencias en registros de datos existentes usando sentencias `UPDATE` e `INSERT`.
- **Automatización:** Automatización de valores de entrada mediante el uso de funciones integradas de fecha (`GETDATE()`, `DATEDIFF()`).
